# AI SaaS MVP (ai-saas-mvp)

## Feature Context

Build an end-to-end functional AI SaaS MVP inside the existing `smith` Nx monorepo. User priorities: it must work end to end; code must be simple and readable over optimized; only established technologies and standards.

Core functionality (as declared by the user):
- Chat with per-user history; authentication with hashed passwords.
- Roles: `user` and `admin`; the admin audits other users' sessions.
- Every generation is persisted in the user's history.

Target architecture (as declared by the user):
- `apps/api` (Node + NestJS), `apps/dashboard` (React + Vite), `apps/landing` (Astro); shared code in `lib/`.
- Storage: "SQLite with Convex" (interpretation to be resolved in Specify/Clarify).
- Model provider `agent-router` and orchestration system `agent-runtime`: DEFERRED for this first version.

Modules: Strapi CMS (user and web-content management; existing `apps/identity-cms`), Convex (conversation and session-history management), Landing (login/register + SaaS presentation), Dashboard (main chat + chat viewer/selector + model selector).

Required deliverables: `.env.example` with all variables, seed with test data, README with project startup instructions.
